# homebrew-tessera

A [Homebrew](https://brew.sh) tap for **[Tessera](https://github.com/tedyno/Tessera)** — a
fast, native database client for macOS.

```sh
brew tap tedyno/tessera
brew trust tedyno/tessera
brew install --cask tessera
```

`brew trust` is required because Homebrew 6 refuses to load a cask from a third-party tap
until you confirm you trust it.

Tessera is signed with a self-signed certificate but **not notarized**, because
notarization requires a paid Apple Developer account and Tessera is an open-source project
without one. macOS therefore refuses to open it on the first launch: dismiss the warning,
then go to **System Settings ▸ Privacy & Security** and click **Open Anyway**. You only
have to do this once.

That is also why Tessera cannot live in the official `homebrew/cask` tap, which from
2026-09-01 accepts only apps that pass Gatekeeper.

Updates are handled by Tessera itself (Sparkle), which is what `auto_updates true` in the
cask tells Homebrew — `brew upgrade` deliberately leaves the app alone. To remove Tessera
along with its settings and cached schemas:

```sh
brew uninstall --cask --zap tessera
```

`Casks/tessera.rb` is generated by `Scripts/make-release.sh` in the main repository, so
every release updates it automatically. Edit it there, not here.
